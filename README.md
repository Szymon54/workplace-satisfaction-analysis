# Workplace Satisfaction Analysis

## Overview
This project is a data analysis of a workplace satisfaction survey. The goal of this analysis is to identify key factors that influence employee satisfaction and to find statistical correlations between different workplace variables. The project was completed as part of my Business Information Technology studies at HAMK.

## Technologies Used
* **Python** (Data processing and analysis)
* **Pandas & NumPy** (Data manipulation)
* **Matplotlib & Seaborn** (Data visualization)
* **SciPy** (Statistical testing)
* **Jupyter Notebook** (Interactive coding environment)

## Key Features & Methodology
1. **Data Cleaning:** Processed the raw Excel survey data (`.xlsx`) to handle missing values and format data types.
2. **Exploratory Data Analysis (EDA):** Created visual representations of the data using Seaborn and Matplotlib to identify trends.
3. **Statistical Analysis:** 
   * Conducted **Chi-square tests** to find significant relationships between categorical variables (e.g., department and satisfaction levels).
   * Used **T-tests** to compare means between different employee groups.
